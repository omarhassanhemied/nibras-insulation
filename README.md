# لاندينج بيدج مؤسسة نبراس للعزل

صفحة ثابتة (HTML + CSS + JavaScript عادي، بدون فريمورك) جاهزة للإعلانات. تشتغل على GitHub Pages أو Vercel أو Netlify.

## الملفات
```
index.html          الصفحة
css/style.css       التصميم
js/config.js        ← كل بيانات الشركة والأرقام والتتبع (عدّل هنا)
js/main.js          المنطق (لا تحتاج تعدله)
assets/logo/        اللوجو (مقصوص من الصورة الأصلية بدون تعديل)
assets/hero|services|projects|about|backgrounds/   فاضية لصورك
IMAGE_PROMPTS.md    برومتات الصور
```

## الرفع
**GitHub Pages:** أنشئ Repository ← ارفع محتويات المجلد (index.html في الجذر) ← Settings ← Pages ← Branch: main / root.

**Vercel / Netlify:** اسحب المجلد أو اربط الـ Repository. لا يوجد Build، والمجلد الجذر هو نفسه.

**من الموبايل:** استخدم ZIP الثاني (`nibras-mobile-upload.zip`) وفيه index.html في الجذر مباشرة.

## تغيير البيانات (من js/config.js)
- **الرقم:** `phones.primary` (أي صيغة، يتحول لـ +966 تلقائياً في الاتصال والواتساب).
- **المدن:** `cities: ["الدمام"]` وتظهر في قسم التواصل.
- **العنوان:** `address` (يظهر في الفوتر فقط إذا كُتب).
- **الإيميل:** اكتبه في `email` ثم `showEmail: true`.
- **السوشيال:** `social.instagram` وغيرها (تظهر فقط إذا كُتبت).
- **الخدمات في الفورم:** `services`.
- **آراء العملاء:** أضف في `testimonials` آراء حقيقية فقط. القسم مخفي تلقائياً لحد ما تضيف رأياً.

## التتبع
اكتب المعرّف في `tracking` وسيُحمَّل الكود تلقائياً (لا يوجد كود قبل ذلك):
`gtm` (GTM-XXXX) و`ga4` (G-XXXX) و`metaPixel` و`tiktokPixel`.

الأحداث التي ترسلها الصفحة:
- ضغطة اتصال أو واتساب: `click_call` / `click_whatsapp` (Meta وTikTok: Contact).
- إرسال الفورم: `generate_lead` (Meta: Lead، TikTok: SubmitForm).

**لازم تتأكد بعد النشر** من البكسل بـ Meta Pixel Helper وTikTok Pixel Helper وGTM Preview. لم أستطع تجربتها من هنا لأن الإنترنت مغلق.

## المعرض والصور
صور الهيرو والخدمات ومن نحن مكانها جاهز: ضع الملفات بالأسماء الموجودة في `IMAGE_PROMPTS.md` وتظهر تلقائياً بدون تعديل كود.
قسم **معرض الأعمال** مخفي تلقائياً (وكذلك رابطه في القائمة) لحد ما تضيف صوراً حقيقية. ضع الصورة (WebP) في `assets/projects/` ثم في `config.js` داخل `gallery` أضف:
`{ cat: "roof", title: "عزل سطح", src: "assets/projects/roof-01.webp", real: true }`
التصنيفات: `roof` أسطح، `bath` حمامات، `tank` خزانات، `leak` كشف تسربات. برومتات توليد الصور في `IMAGE_PROMPTS.md`. الصفحة بدون صور حقيقية شكلها نظيف، لكن صور أعمالهم الفعلية هي أكبر ما يرفع الثقة.

## راجع قبل النشر ⚠
1. **الخدمات الأربع** (عزل الأسطح، الحمامات والمطابخ، الخزانات، كشف التسربات): اللوجو يذكر "عزل مائي • كشف تسربات المياه" فقط. راجع التقسيم والوصف مع العميل.
2. **وعود الصفحة** (نحدد المشكلة قبل الحل، نتفق على نطاق العمل قبل البدء، خطوات العمل الأربع): تأكد إنها تطابق طريقة عملهم فعلاً.
3. **الاسم الإنجليزي** `Nibras Insulation` غير موجود في اللوجو (للتتبع الداخلي فقط).
4. **المدن والعنوان والإيميل والسوشيال:** فاضية عمداً ولا تظهر حتى تتأكد.
5. **الرسمان التوضيحيان** (طبقات العزل في الهيرو ورسم التسرب في قسم التشخيص) عليهما كلمة "رسم توضيحي"، وهما شرح عام وليسا مشروعاً للشركة.
6. **Open Graph:** `og:image` يحتاج رابط كامل بعد ربط الدومين (مثال: `https://yourdomain.com/assets/logo/og-image.jpg`). وفي `index.html` الـ JSON-LD فيه الهاتف، غيّره لو تغير الرقم.
7. **الخطوط** (Readex Pro وAlmarai) تُحمَّل من Google Fonts. لو حبيت استضافتها محلياً حمّلها وضعها في `assets/fonts`.
8. الفورم يفتح واتساب برسالة جاهزة ولا يرسل شيئاً بنفسه، ولا توجد رسالة نجاح وهمية.
